# Source Provenance and Code Reuse: ClusterGuard

ClusterGuard is an autonomous cloud infrastructure guardrail and contract verification framework created by adapting verification patterns and formal mutation testing from **IntentProof** (mutation testing, contract drift, incident replay). Existing MIT license notices are retained. The `intentproof/` library provides the core mutation testing engine for validating guardrail detection coverage.

The significant engineering work in ClusterGuard is the autonomous cloud resource scheduler, multi-model advisory LLM optimization client (Groq primary with Gemini fallback), pre-declared cryptographic consequence contracts (SHA-256), three-valued independent verifier (`PASS`, `BLOCK`, `UNKNOWN`), false-success zombie ack detection, supply-shock stress testing, and the dark-mode SRE cockpit.
